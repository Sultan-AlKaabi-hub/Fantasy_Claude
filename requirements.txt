# GLOOMFALL — dependencies
#
# Streamlit is the only third-party requirement. Everything else the app uses
# (base64, json, typing) is Python standard library, and the game engine itself
# ships inside app.py as an embedded HTML5 Canvas document — no npm packages,
# no CDN assets, no webfonts, no runtime network calls.
#
# Floor is 1.28: st.toggle arrived in 1.26 and st.rerun in 1.27, and 1.28 is the
# first release where both are stable alongside the component iframe behaviour
# the seal bridge relies on. The upper bound guards against a 2.x line that has
# not shipped yet and could change the component API.

streamlit>=1.28,<2.0
